# @petbot/widget-schema

Ultra-fast Declarative UI & Rule Bytecode Schema, Compiler, and C++20 Header Generator for the ESP32-S3 Pet Robot ecosystem.

## Overview

Companion App users must never see raw code, and the ESP32-S3 cannot recompile C++ when a user creates or downloads custom widgets or automation routines.

This package validates human-friendly JSON/YAML generated by the AI Studio using Zod, and compiles it into integer-indexed binary MessagePack bytecode prefixed with an 8-byte header (`PBWG`, schema version, and CRC16-CCITT). All string state keys are mapped to deterministic `uint8` slot indices (`0..63`), and all hex colors are converted into packed 16-bit RGB565 integers at compile time.

The ESP32-S3 renders directly from Octal-SPI PSRAM at 60 FPS with:
- Zero string comparisons in the render loop.
- O(1) state variable reads/writes (`stateSlots[slotIdx]`).
- Pre-packed RGB565 colors directly writable to SPI TFT DMA framebuffers.
- Instant roundtrip compilation in ~0.15ms (< 1ms).

## Declarative Schema Structure (`WidgetPackageSchema`)

1. **`manifest`**:
   - `id`: Unique identifier slug (max 64 chars).
   - `name`: Human-readable display title (max 24 chars).
   - `version`: Strict semver string.
   - `author`: Creator name.
   - `iconId`: 16-bit unsigned integer icon ID.
   - `refreshIntervalMs`: Minimum 16 ms (60 FPS limit).
   - `requiresAgenticMode`: Boolean flag gating high-level AI cloud execution.

2. **`state`**:
   - Reactive state dictionary (`Record<string, StateVariable>`), limited to 64 slots.
   - Supported types: `int32`, `float`, `bool`, `string` (max 64 chars).
   - `initialValue` and `persistToSd` flag for non-volatile SD storage persistence.

3. **`ui`**:
   - Screen bounds: `x: 0..127`, `y: 0..159`, `w: 1..128`, `h: 1..160`.
   - Node types:
     - `Container`: Background color (hex/RGB565), border radius, border color, padding, and recursive `children`.
     - `Text`: Dynamic text template with `{{stateKey}}` interpolation, font sizes (`sm`, `md`, `lg`, `xl`), color, and text alignment (`left`, `center`, `right`).
     - `ProgressBar`: Bound to a state slot, min/max limits, foreground/background colors, and orientation (`horizontal`, `vertical`).
     - `Sparkline`: Real-time history telemetry curve, line width, min/max range, and stroke color.
     - `Icon`: Builtin icon ID, color, scale factor.
     - `PetExpression`: High-level emotion state (`IDLE`, `HAPPY`, `CURIOUS`, `SLEEPY`, `FOCUSED`, `SPEAKING`, `LISTENING`, `ALERT`) and size.
     - `List`: Items binding, row height, and active item highlight color.

4. **`triggers`**:
   - Hardware & system events: `ON_TOUCH_TAP`, `ON_TOUCH_DOUBLE_TAP`, `ON_TOUCH_LONG_PRESS`, `ON_TOUCH_PETTING`, `ON_TIMER_TICK`, `ON_LOAD`, `ON_HARNESS_EVENT`.
   - Conditions: `stateKey`, `operator` (`EQ`, `NEQ`, `GT`, `LT`, `GTE`, `LTE`), `compareValue`.
   - Action pipelines:
     - `MUTATE_STATE`: Target key, operation (`SET`, `INCREMENT`, `DECREMENT`, `TOGGLE`), optional delta value.
     - `PLAY_SOUND`: Sound ID (`CHIRP`, `PURR`, `SUCCESS`, `WARNING`, `TICK`, `BEEP`), frequency in Hz, duration in ms.
     - `SET_EXPRESSION`: Emotion state, duration in ms.
     - `EMIT_HARNESS_RPC`: Action ID, risk tier (`TIER_1_SAFE`, `TIER_2_WORKFLOW`, `TIER_3_2FA_REQUIRED`), payload dictionary.
     - `NAVIGATE_PAGE`: Target widget ID.

## Binary Bytecode Format

```
+---------------------------------------------------------------+
| Byte 0..3: Magic "PBWG" (0x50 0x42 0x57 0x47)                 |
| Byte 4..5: Schema Version (uint16 LE)                         |
| Byte 6..7: CRC16-CCITT Checksum over payload (uint16 LE)       |
+---------------------------------------------------------------+
| Bytes 8..N: Compact MessagePack Encoded Widget Bytecode       |
+---------------------------------------------------------------+
```

## Tooling Commands

```bash
# Generate C++20 bytecode header (petbot_widget_bytecode.h)
pnpm --filter @petbot/widget-schema codegen:headers

# Build TypeScript package to dist/
pnpm --filter @petbot/widget-schema build

# Run unit and performance tests
pnpm --filter @petbot/widget-schema test
```
